Instellingen

Rondetijd
GeluidStaat je iPhone op stil, dan hoor je niets.
Kantelrichting omdraaienGoed = omhoog, pas = omlaag.

Tip: tik in Safari op Deel en kies "Zet op beginscherm". Dan start Kop Op als app, schermvullend en ook offline.

  1. Tik op Start en sta toegang tot beweging toe als je iPhone erom vraagt.
  2. Houd de telefoon liggend tegen je voorhoofd, scherm naar de anderen. Na 3 tellen begint het.
  3. Geraden? Knik: scherm naar de grond. Te moeilijk? Kop omhoog: scherm naar het plafond.

Spelcode

De anderen kiezen "Wie ben ik?", tikken op "Meedoen met een code" en typen deze code over.

Deze code klopt niet. Kijk nog eens op de telefoon van wie het spel startte.

Welke speler ben jij?

Geef iedereen een ander nummer, dan krijgt iedereen een ander woord.

  1. Tik op Start en houd je telefoon liggend tegen je voorhoofd. Jij ziet je eigen woord niet, de anderen wel.
  2. Stel om de beurt ja/nee-vragen, zoals "Ben ik een dier?". Is het antwoord ja, dan mag je doorvragen. Bij nee is de volgende aan de beurt.
  3. Tik bij elke vraag op het scherm, of laat iemand anders tikken. Zo telt je telefoon je vragen.
  4. Goed geraden? Knik en houd even vast. Wil je opgeven, houd dan je kop een tel omhoog. Wie de minste vragen nodig had, wint.
